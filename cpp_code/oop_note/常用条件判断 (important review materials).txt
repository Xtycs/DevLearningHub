***new new[ ] delete delete[ ]区别***

一.
new和delete配对使用，new[ ]和delete[ ]配对使用

// 使用 new 分配单个对象的内存

delete[] arr;

***克隆的两种方法***

1.copy constructor
util2::Bytes bt3 = util2::Bytes(bt2);//初始化的同时直接创建，思路是创建一定大小空间，直接用内存操作函数全部复制

2.overloading operator =

bt4 = bt2; //先创建后克隆，bt2数据的内存大小很可能不等于原先bt4，所以思路是删除原先bt4的内存分配的数据并创建开辟新内存放新数据，原本的bt4依然存在，不过此时依然返回*this并作为&reference返回，确保连续赋值==时依然有效

***delete误区***

一个误区要注意，使用delete删除了某个指针所指向的空间后，指针本身依然存在并指向已删除空间，要重置为nullptr,避免悬挂指针问题
nullptr包含在std::nullptr-t中，在c++中不要使用NULL

>>>>>>***Class's Underlying logic***<<<<<<
在克隆一个类或结构体时，如果都是基本数据类型，没有任何问题，如果有嵌套的类成员，要求嵌套的类有自己的copy constructor
new Song;//开辟空间并存入默认的Song
new Song(s); //开辟空间并使用默认复制构造函数复制s的数据

从而实现代码量极小的克隆函数 (注意这不是copy constructor)
Song *clonesong = new Song(s);
return clone_song;
注意，这种机制只适用于复制构造函数。对于其他类型的函数，如赋值运算符或移动构造函数，你需要为每个类提供一个函数。这是因为编译器生成的默认函数可能不会按照你期望的方式工作。例如，编译器生成的默认赋值运算符会逐个赋值每个成员，这对于需要深复制的成员可能是错误的。

不过这一切的前提是嵌套的子类当中特殊成员都有自己的copy constructor
特殊成员的copy constructor是由内存操作函数实现的
addr_ = new char[bt.len_];
std::memmove(addr_, bt.addr_, bt.len_);

***clone function | copy constructor | = overloading***
1. 克隆函数 是一个普通的成员函数或者全局函数，创建新对象，存在现有对象
Song original_song;
Song *cloned_song = clone_song(original_song); // Clone function is called here

2. copy constructor无返回值,在新对象创建时调用，创建新对象，存在现有对象
Mpr::Music_player player1;
Mpr::Music_player player2 = player1; // Copy constructor is called here

3. = overloading 存在新对象，存在现有对象，是已存在的对象之间赋值
Mpr::Music_player player1;
Mpr::Music_player player2;
player2 = player1; // Copy assignment operator is called here
重载运算符不依赖成员的copy constructor, 而是在已有的内存中存储新元素，不过特殊数据需要在释放清除后存入

***初始化列表***
确保自建的类都有copy constructor的前提下，如果存在const or reference数据类型才需要使用初始化列表
class MyClass {
private:
    const int const_member;
    int& ref_member;

public:
    MyClass(int value, int& ref) : const_member(value), ref_member(ref) {
        // Constructor body
    }

    MyClass(const MyClass& other) : const_member(other.const_member), ref_member(other.ref_member) {
        // Copy constructor body
    }
};
注意static的数据不要放进去，那个在创建时就自动输入了

     /* Provide the missing code */

     ~Pair();
     Pair &operator=(const Pair &p1);

————————————————————————————

#include "pair.h"
using std::cout;
Pair::Pair(int a,int b){
    p=new struct pair;
    p->a=a;
    p->b=b;
};

Pair::Pair(){
    p=new struct pair;
    p->a=0;
    p->b=0;
};

Pair::~Pair(){
    std::cout<<"The Pair with(" <<p->a<<","<<p->b<<") is deleted"<<std::endl;
    delete p;
}

Pair Pair::operator+(const Pair &p1){
    return Pair(p->a+p1.p->a,p->b+p1.p->b);
};

Pair &Pair::operator=(const Pair &p1){
    if (this==&p1)
    {
        return *this;
    }
    delete p;
    p=new struct pair;
    p->a=p1.p->a;
    p->b=p1.p->b;
    return *this;
}

Pair Pair::operator-(){
    return Pair(-(p->a),-(p->b));
};

ostream &operator<<(ostream &os,const Pair &p1){
    os<<"("<<p1.p->a<<","<<p1.p->b<<")"<<std::endl;
    return os;
}

Pair::operator bool() const{
    return p->a!=0||p->b!=0;
}
